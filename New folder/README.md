# React Five-Page Shop

Five pages using React Router:
- /
- /shop
- /basket
- /customer
- /about

React patterns are based on the supplied course files: components, JSX, props, useState, events, controlled forms, spread, filter, map and reduce, plus Tailwind.

React Router is included because it was explicitly requested for the five-page navigation; it was not shown in the supplied course slides.

Run:

npm install
npm run dev
